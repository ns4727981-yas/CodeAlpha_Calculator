## 📌 Description

This project is a web-based basic calculator designed to perform standard arithmetic operations along with advanced features like square root, percentage, and memory recall. Built with clean code practices, it avoids `eval()` risks by utilizing strict execution contexts and includes error handling for invalid operations (e.g., division by zero).

---

## ✨ Features

* **Basic Arithmetic:** Addition (+), Subtraction (-), Multiplication (×), Division (÷).
* **Advanced Operations:** Square root ($\sqrt{x}$) and Percentage calculation (%).
* **Memory Functions:** `MC` (Clear), `MR` (Recall), `M+` (Add to Memory), `M-` (Subtract from Memory).
* **Keyboard Support:** Full input support using standard keyboard numbers, operators, `Enter` (calculate), `Backspace` (delete), and `Escape` (clear).
* **Responsive & Intuitive UI:** Styled layout with interactive button states and clear display focus.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and button layout.
* **CSS3:** Custom layout design, CSS Grid, hover effects, and responsive styling.
* **JavaScript (ES6):** Core calculation logic, memory management, and event listeners.
